# LIGHTS OUT! The Bolt & Dot Show — ملف المشروع الكامل

لعبة جري وإطلاق ومعارك زعماء بأسلوب كرتون الثلاثينات، تشتغل في المتصفح. كل الرسوم مرسومة بالكود، وكل الموسيقى والأصوات تتولّد داخل المتصفح بدون أي ملفات صور أو صوت.

## تشغيل اللعبة فوراً
افتح الملف `dist/index.html` في أي متصفح (كروم أو إيدج أو فايرفوكس). ما يحتاج إنترنت ولا تثبيت، لأن الخطوط مدمجة داخل الملف.

## محتويات الملف
| المسار | وش فيه |
|---|---|
| `dist/index.html` | اللعبة جاهزة في ملف واحد (هذا اللي تفتحه أو تنشره) |
| `src/01_core.js` | المحرك: الحلقة الرئيسية، الأزرار، الحفظ، الإعدادات، الانتقالات |
| `src/02_draw.js` | أدوات الرسم الكرتوني، الخطوط، تأثيرات الفيلم القديم، الجزيئات |
| `src/03_audio.js` | الموسيقى (جاز وراغتايم) والمؤثرات الصوتية وأصوات الشخصيات |
| `src/04_player.js` | Bolt وDot: الحركة والأسلحة الخمسة وEX والضربات الخارقة والصد |
| `src/05_stage.js` | ساحة اللعب: الطلقات والتصادم وواجهة اللعب والتقييم |
| `src/06_boss_base.js` | نظام الزعماء ومراحلهم |
| `src/07_bosses_a.js` | الزعماء 1-4: النحلة، الساحر، آلة القمار، القرصان |
| `src/08_bosses_b.js` | الزعماء 5-8: وحش البحر، العالم المجنون، التنين، Baron Von Gloom |
| `src/09_levels.js` | العوالم الخمسة ومراحل الجري والأعداء والمخاطر |
| `src/10_ui.js` | كل القوائم: الخريطة، المتجر، التجهيز، الإعدادات، النتائج... |
| `src/12_upgrade.js` | الإضاءة والجو والأصوات المحيطة والزعماء الصغار والإنجازات |
| `src/99_main.js` | تشغيل اللعبة |
| `build.py` | يجمع ملفات `src` في `dist/index.html` |
| `test/` | سكربتات الاختبار الآلي (Playwright) |

## كيف تعدّل وتبني
1. عدّل أي ملف داخل `src`.
2. شغّل: `python3 build.py`
3. افتح `dist/index.html` وجرّب.

ملاحظة: `build.py` يدمج الخطوط من مجلد `fonts/` الموجود داخل هذا الملف. لو نقلت المشروع، خله جنب `build.py`.

## التحكم (لاعب واحد)
| الحركة | الزر |
|---|---|
| تحرك وتصويب | W A S D (أو الأسهم) |
| قفز / صد | J (أو Z أو مسافة) |
| إطلاق | K (أو X) |
| اندفاع | L (أو C) |
| ضربة EX / خارقة | I (أو V) |
| تبديل السلاح | U (أو Q) |
| تثبيت التصويب | O (أو E) |
| إيقاف مؤقت | Esc |

اللاعب الثاني: الأسهم + أرقام النمباد (1 قفز، 2 إطلاق، 3 اندفاع، 0 EX). تقدر تغيّر أي زر من CONTROLS. ويدعم يد التحكم واللمس.

الصد: اقفز وخلك ضاغط زر القفز، وانزل على أي شي وردي.

## وش تقول لكلاود في حسابك الجديد
ارفع هذا الملف وقل مثلاً:
> هذا مشروع لعبتي LIGHTS OUT. اقرأ README_AR.md وملفات src، وكمّل التطوير على نفس المشروع بدون ما تحذف شي. التعديلات في src ثم شغّل build.py.

## أشياء معروفة لسا ما خلصت
- الرسوم مرسومة بالكود، مو رسم يدوي إطار بإطار.
- بعض هجمات الزعماء تستخدم وضعية عامة بدل حركة خاصة.
